# اتحاد قبائل العلاونة - موقع HTML/CSS

تم تحويل موقع React/TypeScript الخاص باتحاد قبائل العلاونة إلى HTML/CSS عادي مع JavaScript للتفاعل.

## الملفات

- `index.html` - الهيكل الرئيسي للموقع
- `styles.css` - التنسيقات والتصميم
- `script.js` - الوظائف التفاعلية
- `assets/` - الصور والمواد المرئية

## المميزات

### التصميم
- ✅ تصميم متجاوب (Responsive Design)
- ✅ دعم الاتجاه من اليمين لليسار (RTL)
- ✅ خطوط عربية (Cairo و IBM Plex Sans Arabic)
- ✅ نظام ألوان متكامل مع متغيرات CSS
- ✅ ظلال وتأثيرات بصرية حديثة

### الوظائف التفاعلية
- ✅ عرض شرائح تلقائي في القسم الرئيسي
- ✅ تنقل سلس بين الأقسام
- ✅ قائمة تنقل متجاوبة للهواتف
- ✅ مؤشرات القسم النشط
- ✅ دعم اللمس للهواتف الذكية
- ✅ تحكم بلوحة المفاتيح

### الأقسام
1. **الصفحة الرئيسية** - عرض شرائح مع العنوان الرئيسي
2. **التعريف والنسب** - معلومات عن القبيلة وانتشارها
3. **التواصل والمشاركة** - دعوات للمشاركة ومبادئ التواصل

## كيفية التشغيل

### تشغيل محلي بسيط
1. افتح `index.html` في المتصفح مباشرة

### تشغيل مع خادم محلي (مستحسن)
```bash
# استخدام Python
python3 -m http.server 8000

# أو استخدام Node.js
npx serve .

# أو استخدام PHP
php -S localhost:8000
```

ثم اذهب إلى `http://localhost:8000`
